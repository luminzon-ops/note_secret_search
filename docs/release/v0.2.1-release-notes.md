# Note Secret Search v0.2.1 Release Notes

Version: `0.2.1+3`

Tag: `v0.2.1`

## Highlights

- Biometric unlock now copies platform key bytes into writable, application-owned buffers before cleanup.
- Authentication results received while the system biometric dialog leaves the app temporarily inactive can complete without being discarded.
- Sensitive content remains shielded until the app is fully resumed.
- Cancelling or failing system authentication restores the secure lock screen instead of leaving a persistent dark surface.
- Unexpected authentication bridge errors restore button state and expose only generic user-facing messages and stable log events.

## Compatibility

- Database format, native keyring envelope, debug signing certificate, and existing user data are unchanged.
- Android SDK, ABI, tokenizer, ONNX Runtime, and llama.cpp packaging policy remain the same as v0.2.0.
- The Huawei debug APK is a local upgrade-validation artifact only and is not a public release asset.

## Distribution

- The default release workflow creates a source-only draft Release.
- Debug APK, unsigned APK, and AAB artifacts are not attached to the public draft.
- Formal signing and public binary publication remain disabled until the protected signing environment is configured.
