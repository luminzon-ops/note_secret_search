# Note Secret Search v0.2.0 Release Notes

Version: `0.2.0+2`

Tag: `v0.2.0`

## Highlights

- Release-ready CI now builds Android artifacts once and reuses the same APK/AAB inputs for audit, API smoke, signing, attestation, and draft release.
- Sensitive clipboard copies now use a secure controller with generation checks, current-value comparison, timeout cleanup, dispose cleanup, and best-effort lock cleanup.
- External provider endpoints are restricted by build mode: Release requires HTTPS; Debug only allows loopback HTTP for local services.
- Android version metadata now comes from `pubspec.yaml`; Android build settings read shared Gradle properties.

## Included Runtime Evidence

- Phase 6 llama.cpp AAR SHA-256 remains `9583871b4179ae48ce3c57796fad21580167de4183ca6c28efdc2ed4724f9b41`.
- Phase 8 Huawei SPN-AL00 / API 29 gates remain the native runtime ledger baseline for BGE and sensitive runtime logs.
- Tokenizer assets are expected in APK; MiniCPM, mtmd, and mmproj assets remain absent.
- On August 10, 2026, the Huawei closeout gate passed on serial `H8B4C19731000256` with `0.2.0+2`, the existing certificate, clean runtime logs, and unchanged user model files. The backup and evidence path is recorded in the release ledger.

## Not Included

- MiniCPM / multimodal runtime is not implemented in v0.2.0.
- Remote sync and remote catalog expansion are not included.
- R8, resource shrinking, and Flutter obfuscation remain disabled until JNI/reflection/native runtime characterization exists.
- The Huawei debug APK is a local upgrade-validation artifact only and is not a public release asset.
- Formal signing and public binary publication remain disabled until the protected signing environment is configured.
